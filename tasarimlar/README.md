# Tasarımlar (UI / UX)

Bu klasör, **Akıllı Belge Tarayıcı** uygulamasının geliştirme sürecinde hazırlanan:

- Taslak ekran çizimleri (Wireframe)
- Figma arayüz tasarımları (Ana ekran, Kamera ekranı, Kırpma/Perspektif düzenleme ekranı, Filtre ve PDF önizleme ekranı)
- Uygulama ekran görüntüleri ve görsel materyaller

için ayrılmıştır.
